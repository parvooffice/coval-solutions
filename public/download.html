Review code where you work.

Everything comes in one file and needs nothing else installed. Scoring runs on your computer, so your code never leaves it. COVAL uses the internet only for your account, notifications, and AI explanations.

COVAL for Windows

Your COVAL dashboard as an app, with Windows notifications for team invites and Feed replies, scoring for any folder on this computer, and the coval command for your terminal. Updates install themselves.

Download for Windows
  1. Open COVAL-Setup.exe. It installs and opens COVAL, with no options to choose.
  2. Sign in with GitHub, and you're done.

Windows 10 or 11, 64-bit. If Windows shows “Windows protected your PC”, click More info → Run anyway (we're getting the app signed). After installing, open a new terminal and run coval scan.

VS Code extension

Inline warnings on the exact line, a COVAL scores panel, and your overall score in the status bar.

Install in VS Code Download for VS Code (Windows, 9 MB)
  1. In VS Code, open Extensions (Ctrl+Shift+X), click ⋯ → Install from VSIX…
  2. Choose the downloaded file, then click the COVAL icon in the sidebar → Score workspace.

No Python needed: the extension includes the COVAL engine.

Other ways to install

Just the coval command (any operating system)

COVAL for Windows already includes it. On macOS or Linux, or without the app, install it with Node.js 20+ (this version runs the agents with Python 3.10+):

npm install -g https://coval-solutions-w92u.vercel.app/downloads/coval-cli-0.2.0.tgz
coval scan              # score the current folder
coval review            # compare your branch with main
coval review --comment  # post the review on the pull request
How is the app different from the website?

It's the same COVAL, plus notifications while it runs in the system tray, scoring folders on this computer, and the coval command. To start it with Windows, right-click the COVAL tray icon → Start with Windows.

Which agents run on my computer?

Six of them: Readability, Test coverage, Performance, Maintainability, Scalability, and Standards compliance. The web app runs all ten on GitHub repositories and adds AI fix explanations, score history, sharing, teams, and the Feed.

Can I skip folders?

Yes. Add a .coval.yml file with an ignore: list to your repository; the app, the extension, the CLI, and the web app all respect it.

How do I uninstall?

Windows Settings → Apps → Installed apps → COVAL → Uninstall. It also removes the coval command.
