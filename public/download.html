DOWNLOADS · VERSION 0.1.0

Review code where you work.

The VS Code extension and the coval CLI run COVAL's review agents on your own computer — your code never leaves it. Both give the same scores and pull request reviews as the COVAL GitHub App. They're free.

VS Code extension

Inline warnings on the exact line, a COVAL scores panel, and your overall score in the status bar.

Download for VS Code (.vsix, 37 KB)
  1. Open VS Code and go to Extensions (Ctrl+Shift+X).
  2. Click ⋯ at the top of the panel, then Install from VSIX…
  3. Choose the downloaded coval-code-review-0.1.0.vsix.
  4. Open a project folder, click the COVAL icon in the sidebar, then Score workspace.

Or from a terminal: code --install-extension coval-code-review-0.1.0.vsix

coval CLI

Score any folder and review a branch like a pull request. Post the review on GitHub and block merges when scores drop.

Download the CLI (.tgz, 30 KB)

Or install straight from this site:

npm install -g https://coval-solutions-w92u.vercel.app/downloads/coval-cli-0.1.0.tgz
coval scan              # score the current folder
coval review            # compare your branch with main
coval review --comment  # post the review on the pull request

Requirements

What do I need installed?

Python 3.10 or newer for the agents. The CLI also needs Node.js 20 or newer. If VS Code says Python was not found, open Settings (Ctrl+,), search COVAL Python Path, and set it to python, python3, or py.

How is this different from the web app?

The extension and CLI run six agents locally (Readability, Test coverage, Performance, Maintainability, Scalability, Standards compliance). The web app runs all ten, adds AI fix explanations, score history, sharing, teams, and the Feed.

Can I skip folders?

Yes. Add a .coval.yml file with an ignore: list to your repository; the extension, CLI, and web app all respect it.
