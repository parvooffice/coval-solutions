Questions

Is my code stored?

No. Repositories are downloaded to a temporary folder, scored, and deleted right after the run. Only the scores and findings are saved to your account. See Privacy.

Is it AI?

The ten review agents are deterministic analyzers, so the same code always gets the same score. AI (OpenAI) is used only when you ask the assistant a question or click “Explain & fix”.

Can I score private repositories?

Yes, on Pro: install the COVAL GitHub App on the repositories you choose. Access is read-only and you can revoke it anytime in GitHub.

How are scores calculated?

Each agent scores weighted categories from 0 to 100; the overall score is their average. Open “Score breakdown” on any agent card to see the categories, or look at the sample report for Flask.
