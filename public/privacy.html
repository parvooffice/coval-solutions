PRIVACY

Your code stays yours.

This page explains, in plain language, what COVAL does with your code and data.

Your source code

  • When you score a repository, COVAL downloads it to a temporary folder, runs the review agents, and deletes the folder as soon as the run finishes. Source code is never stored in our database.
  • The review agents read your code; they never run it.
  • The VS Code extension scores code on your own computer. It does not upload anything.
  • Private repositories are read only through the COVAL GitHub App, with read-only access to the repositories you choose. You can revoke it anytime in GitHub settings.

What we store

  • Your account (from Google or GitHub sign-in), profile details you choose to add, and connections and messages you create.
  • Evaluation results: scores, short summaries, and findings (file paths, line numbers, and descriptions).
  • Usage counts for plan limits, and your plan status from Razorpay. COVAL never sees or stores card or UPI details.

AI features

When you ask the report assistant a question or click “Explain & fix”, COVAL sends the relevant parts of your report and, for “Explain & fix”, about 40 lines of the related code to OpenAI to generate the answer. OpenAI does not use API data to train its models. Nothing is sent to an AI provider unless you use these features.

Sharing

Your results are private unless you share them. Share links and README badges work only for public repositories, and you can remove a link at any time. Team admins can see the scores of members on their team.

Deleting your data

On the Plan page in the dashboard, choose Delete my evaluation data to remove all saved reports, dismissed findings, and share links immediately. To delete your whole account, contact the COVAL team.
